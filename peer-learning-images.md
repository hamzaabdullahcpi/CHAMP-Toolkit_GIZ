# Peer learning example images

Suggested photos for the 43 peer learning examples, in the order they appear on the Actions pages. Each row has a subject plus searches on Unsplash (free), Wikimedia Commons (free, but check each image's licence and credit line) and Depositphotos (paid).

**Selection criteria:** real landscape or cityscape photos of the place named in the example, no heavy HDR or filters, no AI-generated images. Unsplash and Depositphotos both host some AI and heavily edited images, so check each one before using it. Pick landscape-orientation images that still crop well to a square half.
